# morse-code -- solution

## TL;DR

International Morse. Letters split by spaces, words by `/`.

## Steps

1. Map each dot/dash group back to a letter with a Morse table.
2. The message is `MORSE CODE IS EASY`.
3. Lowercase and join words with underscores inside `NCTF{...}`.

Run `python3 solve.py`.

## Flag

`NCTF{morse_code_is_easy}`
